# Chaskay para Warp

Tema oscuro para [Warp](https://www.warp.dev/), inspirado en tonos azules, violetas y verdes suaves.

## Instalación

1. Descargá [`themes/chaskay.yaml`](./themes/chaskay.yaml).
2. Copialo en la carpeta de temas de Warp:

   ```text
   ~/.warp/themes/
   ```

3. Reiniciá Warp y seleccioná **Chaskay** desde la configuración de temas.

## Colores

- Fondo: `#191D25`
- Texto: `#D7D9DF`
- Acento: `#3B3D55`
- Cursor: `#B4ACDF`
