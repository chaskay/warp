## Usage

1. Copy/move the theme(s) of your choice from themes/ to your Warp theme directory. 
   - `${XDG_DATA_HOME:-$HOME/.local/share}/warp-terminal/themes` on Linux.
   - `%AppData%\warp\Warp\data\themes` on Windows.  

2. Restart Warp to load the new theme(s).
3. Open Settings > Appearance > Theme and select the theme you would like to use.
